# Breezone — interface web

React 19 + Vite + TypeScript + Tailwind 4 + shadcn/ui. Servie en fichiers statiques par le serveur
Breezone (`BREEZONE_WEB_DIR`) ; en développement, `npm run dev` relaie `/api` vers `localhost:8427`
(voir `../scripts/dev.sh`).

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build    # → dist/
```
